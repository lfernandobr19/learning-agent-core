### Componente React de Status dos Agentes

Para implementar um componente React que exibe o status dos agentes e garantir sua integridade através de testes robustos com Vitest, seguiremos uma abordagem modular e testável.

#### Objetivo
O objetivo é criar um componente React `AgentStatus` que recebe dados sobre os agentes e exibe seus estados (ativo/inativo) de forma visualmente agradável. Este componente será responsável por fornecer uma visão clara do status dos agentes, facilitando o monitoramento e tomada de decisões.

#### Tarefas por Agente

- **Backend Lead**:
  - Definir a estrutura do componente React `AgentStatus`.
  - Implementar lógica para renderizar os agentes com seus respectivos estados.
  - Escrever testes unitários usando Vitest.

- **Data Engineer**:
  - Ensinar sobre a implementação de estilos condicionais ou classes dinâmicas para renderização dos status.
  - Verificar o comportamento do componente em diferentes estados (ativo, inativo).

- **Frontend Lead**:
  - Integração com APIs externas se necessário.
  - Definir e aplicar estilos responsivos.

- **QA Guardian**:
  - Executar testes de unidade e integração.
  - Verificar a funcionalidade do componente em diferentes cenários.

- **Reliability Lead**:
  - Garantir que o componente seja idempotente, não alterando o estado da aplicação ao ser renderizado várias vezes com os mesmos dados.
  - Implementar lógica de atualização de status dinamicamente.
